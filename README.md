# 一格記事

像 iPhone「提醒事項」一樣的待辦清單網頁 App。把一大段文字貼進去，會自動拆成一個一個提醒事項。

## 功能

- **貼上自動拆格**：每一行、`1.` `①` `-` `•` 這類編號和符號、整段文字的每一句，都會變成一個提醒事項。
- **自動分類**：貼上的文字裡有「工作：」「釣魚遊戲：」這種標題行，會自動建立分類。
- **像 iPhone 一樣操作**：按 Enter 接著新增下一個；往左滑可以詳細資訊、複製、標記、刪除；長按可以拖曳排序。
- **智慧型列表**：今天、已排程、全部、已標記、已完成。
- **日期與提醒**：日期、時間、重複、旗標、優先順序、備忘錄。App 開著時，到時間會跳出提醒。
- **複製**：複製標題、備忘錄，或建立副本；也可以把整個列表複製成文字。
- **備份／還原**：資料存在手機的瀏覽器裡，首頁上方可以下載或複製備份。
- **可以加到主畫面**，沒有網路時也能打開。

## 放上 GitHub Pages

1. 把這個資料夾裡的檔案放進一個 GitHub repository。
2. 到 repository 的 **Settings → Pages**，Source 選 **Deploy from a branch**，Branch 選 `main`、資料夾選 `/ (root)`，按 Save。
3. 等一兩分鐘，網址會是 `https://<你的帳號>.github.io/<repository 名稱>/`。

## 加到手機主畫面

- **iPhone（Safari）**：分享按鈕 → 加入主畫面。
- **Android（Chrome）**：右上角 ⋮ → 加到主畫面／安裝應用程式。

## 注意

- 資料只存在你用的那支手機、那個瀏覽器裡，不會上傳到任何地方。換手機或清除瀏覽器資料前，請先到首頁上方「備份／還原」備份。
- 到時間的提醒只會在 App 開著時跳出來。
