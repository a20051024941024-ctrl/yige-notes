# 一格記事

像 iPhone「提醒事項」一樣的待辦清單網頁 App。把一大段文字貼進去，會自動拆成一個一個提醒事項。

網址：https://a20051024941024-ctrl.github.io/yige-notes/

## 功能

- **現在要做**：首頁最上面自動挑出最該先做的一件（進行中 → 過期 → 今天 → 重點 → 排最前面），按「做完了」就換下一件。
- **記新的事**：首頁直接打字，按 Enter 就記好。
- **貼上自動拆開**：每一行、`1.` `①` `-` `•` 這類編號和符號都會拆開；同一行用「。」「！」「？」「；」隔開的好幾句，也會拆成好幾件。數字和網址裡的「.」不會拆（例如「1.5 公斤」「www.abc.com」）。
- **自動認出日期和時間**：句子裡有「今天、明天、後天、下週一～下週日、星期X、X月X日、X/X、早上、中午、下午、晚上、X點、X點半、X:XX」，會自動設好日期時間，並把這幾個字從標題拿掉。
  - 例：「寄信給阿默 明天下午3點」→ 標題「寄信給阿默」，明天 15:00。
  - 只寫日期就只設日期；沒說早上下午的 1～6 點，當作下午。
  - 貼上一大段時會先出現預覽，每一件認出來的日期都看得到，不要的按 ✕ 取消。只打一件時，下方會跳出「取消日期」。
- **自動分類**：貼上的文字裡有「工作：」「釣魚遊戲：」這種短的標題行，會自動建立分類。預覽裡每個分類都從 1 開始編號。
- **分類看得到**：首頁「我的列表」底下直接列出每個分類和件數，點進去就只看那一類。列表裡上方也有分類圖案可以切換。
- **像 iPhone 一樣操作**：按 Enter 接著新增下一個；往左滑可以詳細資訊、複製、設重點、刪除；長按不動是選單，長按後移動是拖曳排序；也可以用「調整順序」按 ↑↓。
- **智慧型列表**：今天、已排程、全部、重點、已完成、進行中。
- **日期與提醒**：日期、時間、重複、重點、優先順序、內容。App 開著時，到時間會跳出提醒。
- **複製**：複製標題、內容，或建立副本；記住上次複製到哪一件，可以一鍵「複製下一個」。
- **圖片**：每個提醒事項都能放圖片（拍照、相簿、直接貼上），可以放大看、複製圖片、存到手機。
- **登入（Google 或 Email）**：登入後資料存在帳號裡，換手機、清掉瀏覽器都不會不見，多支裝置即時同步。
- **邀請一起記**：列表右上角 ⋯ →「邀請別人一起記」，把連結用 LINE 傳給對方，對方打開就加入（不用登入），兩邊即時同步。可以「指派給」某人，也會顯示誰完成的。
  - 拿到連結的人都能看到並修改這個列表，只傳給你要一起記的人。
- **備份／還原**：可以下載或複製備份，也可以從備份還原。
- **可以加到主畫面**，沒有網路時也能打開；有新版時會自動更新。

## 資料存在哪裡

- **沒登入**：自己的列表、提醒事項和圖片只存在你用的那支手機、那個瀏覽器裡。換手機或清除瀏覽器資料前，請先到首頁上方「備份」。
- **有登入**：自己的列表存在你的帳號裡（Firebase 雲端），只有你自己讀得到；同一個帳號的手機和電腦會同步。
- **共用列表**：存在雲端，拿到邀請連結的人都讀得到、改得到。

## 放上 GitHub Pages

1. 把這個資料夾裡的檔案放進一個 GitHub repository。
2. 到 repository 的 **Settings → Pages**，Source 選 **Deploy from a branch**，Branch 選 `main`、資料夾選 `/ (root)`，按 Save。
3. 等一兩分鐘，網址會是 `https://<你的帳號>.github.io/<repository 名稱>/`。

## Firebase 設定

1. 在 Firebase 後台開一個專案，開啟 **Authentication** 的 Google 和「電子郵件/密碼」登入，並把網址加進「授權網域」。
2. 建立 **Firestore Database**。
3. 把 `firestore.rules` 的內容貼到 Firestore 的「規則」頁面，按「發布」。
4. 把網頁應用程式的設定碼（`apiKey` 那段，本來就是公開的）填進 `index.html` 的 `FIREBASE_CONFIG`。

## 加到手機主畫面

- **iPhone（Safari）**：分享按鈕 → 加入主畫面。
- **Android（Chrome）**：右上角 ⋮ → 加到主畫面／安裝應用程式。

## 注意

- 到時間的提醒只會在 App 開著時跳出來。

## 檔案

| 檔案 | 用途 |
| --- | --- |
| `index.html` | 整個 App（HTML、CSS、JavaScript 都在裡面） |
| `firestore.rules` | Firebase 安全規則（貼到 Firebase 後台） |
| `manifest.webmanifest` | 加到主畫面用的設定 |
| `sw.js` | 離線快取（改版時版本號要加一） |
| `version.json` | 讓 App 知道有沒有新版本 |
| `icon-*.png`、`apple-touch-icon.png` | App 圖示 |
